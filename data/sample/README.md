# SIMULATED sample data

Everything in this folder is **simulated**. It was generated by `src/generate_sample_data.py` (seed 42, as-of date 2026-10-31).
Customers, invoices and amounts are made up.

| File | What it imitates |
|---|---|
| `simulated_ledger_sheet.csv` | CSV export of the Google Sheet that the Form writes to (the AR ledger) |
| `simulated_qbo_invoices.json` | QuickBooks Online API response to `select * from Invoice` |
| `simulated_qbo_payments.json` | QuickBooks Online API response to `select * from Payment` |
| `simulated_planted_problems.csv` | Answer key: the 25 errors planted on purpose (5 missing in QB, 5 missing in Sheet, 6 amount, 6 status, 3 duplicates) |

To regenerate: `make sample` (the output is identical every time).
